macOS

推荐用终端一键安装（curl 下载，避开浏览器隔离标记）。未做 Apple 公证前，系统仍可能要求在「隐私与安全性」里点一次「仍要打开」——这是正常的。

一键安装（推荐，点复制 → 粘贴到「终端」回车）：
curl -fsSL http://175.24.134.228/downloads/install.sh | bash

Intel

Intel Mac

版本 2.0.0 · 大小 — · x86_64

下载 DMG (x64)
1

优先：打开「终端」，粘贴上面的一键安装命令并回车。装完会自动打开。

2

若用 DMG：会多一步「允许终端运行脚本」，再装 app——比一键安装更绕，不推荐。不要只把 app 拖进 Applications。

3

已经装过但仍被拦：终端执行 xattr -cr /Applications/PlainList.app && open /Applications/PlainList.app。

提示：应用使用你部署在公网的 PlainList 后端（同一台服务器 175.24.134.228）。账号 rainhuang / 密码 rainhuang 可直接登录。
关于「Apple 无法验证」：当前包是 ad-hoc 签名（无 Apple 开发者账号公证）。macOS 会拦一次；去设置点「仍要打开」即可，之后一般不再拦。DMG 里的 .command 会再多一次「允许终端」，所以感觉像两步——请改用上面的一键 curl。彻底零提示只能上 Developer ID + 公证。

Android

下载 APK 直接安装（需允许未知来源）。当前为自签名侧载包，非正式应用商店分发。

Android

通用 APK

版本 2.0.11 · 大小 — · arm64/x86_64

下载 APK
1

在系统设置中允许「安装未知应用」/「未知来源」（路径因品牌而异：设置 → 安全 / 应用 → 特殊权限）。

2

用手机浏览器打开本页，点「下载 APK」，下载完成后打开文件安装。

3

若被拦截：回到设置里对该浏览器/文件管理器开启安装许可，再点一次 APK。
